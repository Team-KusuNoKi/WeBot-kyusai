# 11月の救祭

Team.KusuNoKi の謎解きです。冊子と、スマートフォンの会話（WeBot）を往復しながら進みます。ページで見つけた答えを会話へ送ると、次の手がかりが返ってきます。

公開中のチャットは [team-kusunoki.com の『11月の救祭』](https://team-kusunoki.com/11月の救祭/app/) です。

このページには、物語の始まりと、リポジトリの置き場だけを書いています。問題の答えと、その先の展開は `webapp/README.md`、`webapp/dist/scenario.js`、`Kyusai_materials/` に入っています。自分で遊びたい人は、そこを開かずにチャットから始めてください。

## 物語のはじまり

11月祭の京都大学。ミサメ、タツ、アサヒの三人は、冊子に仕込まれた謎を解きながらキャンパスを歩いていく。

答えを会話へ送ると、次に向かう場所と、現地で探す掲示の案内が返ってくる。掲示を見つけてページをめくると、また次の謎が始まる。序盤は、手がかりから次の建物を読み取り、写真を頼りにそこまで歩くところからです。

## このリポジトリ

| 場所 | 中身 |
| --- | --- |
| `webapp/` | 謎解きチャット。画面、会話、進行の保存。起動手順は `webapp/README.md`（制作者向けで、確認手順に答えが書いてある） |
| `webapp/dist/` | 配信している本体。`scenario.js` に問題文・会話・正解がある |
| `Kyusai_materials/` | 冊子スライドの原本画像。問題そのもの |
| `道案内/` | キャンパスを歩くときの案内写真 |
| `表紙・イラスト/` | 表紙と、登場人物の絵 |
| `prototypes/` | チャットに載せる前の試作 |

## 手元で開く

Node.js 18 以降。依存パッケージのインストールは不要です。

```sh
cd webapp
npm run dev
```

表示された `http://127.0.0.1:4173/` を開きます。チャットは `http://127.0.0.1:4173/11月の救祭/app/` です。終了は Ctrl+C。
